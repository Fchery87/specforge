Project entity REQ-031

The Project entity holds id, name, status, ownerId, archivedAt, and deletedAt. Status is one of active, archived, or deleted. deletedAt stays null until soft deletion runs. The entity never stores its artifact list.E7

Claims CLM-0338

Archive invariant REQ-032

Archiving never mutates artifacts. Artifacts are immutable once written, so archive only flips Project.status and stamps archivedAt. Every artifact read path ignores project status, so an archived project stays fully readable.E8E9
